# 最近工作区目录

独立 DSH 插件。不修改 DSH 核心源码，也不修改内置插件文件。

## 行为

- 接管侧边栏和新会话页的工作区目录选择弹窗。
- 首次从主目录打开；点击“打开此目录”时，记住该目录的父级。
- 下次默认进入这个父级，例如上次选 `D:\projects\a`，下次进入 `D:\projects`。
- 根据 Host 返回的祖先路径取父级，不在浏览器中猜测 Windows / POSIX / UNC 路径。
- 上次位置不可访问时回退到主目录。手动输入的无效路径显示错误，不自动跳走。
- 支持路径输入、面包屑、Host 返回的盘符、上一级、隐藏目录及新建文件夹。
- 目录确认仍交给 DSH 原有工作区创建流程。用户确认“打开此目录”时更新历史；浏览或取消不会改变历史。插槽没有创建成功回执，因此即使随后的工作区创建失败，也保留本次确认的位置。

## 保存范围

历史位于当前浏览器 origin 的 localStorage（键 `dsh:recent-folder:v1`），按 Host 主目录隔离。刷新、重启浏览器仍保留；换浏览器、换协议/地址/端口不会共享。同一 origin 下多个配置且 Host 主目录相同会共享记录。存储被禁用时降级为本次页面内记忆。

卸载/禁用插件会恢复内置选择器；localStorage 不主动删除，下次启用可继续使用。

## 安装

在 DSH 插件管理器中安装 npm 包 `dsh-plugin-recent-folder`；也可以通过 `install_bundle` 指定包名 `dsh-plugin-recent-folder@1.0.0` 或本地仓库的绝对目录。

无第三方依赖，无安装脚本，无需构建。不直接编辑 profile 文件。安装影响当前 profile 的全部会话。

若曾安装旧的本地包 `@local/dsh-plugin-recent-folder`，请先在插件管理器中移除旧包，再安装正式包，避免重复注册。已有目录历史仍会保留。

## 开发与检查

- `npm test`：实际历史读写、根路径、Windows/POSIX/UNC 父级、损坏/拒绝存储、元数据与资源测试。
- `npm run check`：JavaScript 语法检查。

Client 使用公开 `slots`、`locale`、`uiWorkspace` 服务。两个 directoryFlow single 插槽以 priority -10 覆盖内置 occupant；卸载时由 Cordis 生命周期恢复内置 occupant。Client 模块不导入 DSH 内部 UI 组件。

为兼容当前运行版（未公开 directoryBrowser 服务），插件提供独立的简洁目录选择 UI，而非复制整套内置 Miller 双栏浏览器。样式使用宿主主题 token，具有焦点约束、Escape 取消、Tab 循环及关闭后的焦点恢复。

图标为本项目原创 SVG。中英文插件元数据与界面文本均已提供。

## 手动验收

1. 从侧边栏新建工作区，输入一个非主目录下的目录并打开。
2. 再次新建，确认落在刚才目录的父级。
3. 取消后从新会话页打开选择器，确认共享位置；刷新页面后再试。
4. 测试不可访问的历史目录时应回退主目录。
5. 测试 Tab / Shift+Tab、Escape、浅色/深色、小屏和盘符导航。

无浏览器控制时只能验证语法、纯逻辑、资源与 live 插槽注册，不能将其视为真实点击和视觉验收。
